## Agent skills

### Issue tracker

Issues 在本仓库的 GitHub Issues 里跟踪（用 `gh` CLI）。See `docs/agents/issue-tracker.md`.

### Triage labels

默认五标签：`needs-triage` / `needs-info` / `ready-for-agent` / `ready-for-human` / `wontfix`。See `docs/agents/triage-labels.md`.

### Domain docs

单上下文：根目录一个 `CONTEXT.md` + `docs/adr/`。See `docs/agents/domain.md`.
